The single most consequential control in the window: `Tuzatish kuchi` (`--lid-open`, 0–1, default 0.5) trades gaze correction against eyelid-geometry drift (10.4-boʻlim — 0.5 is 63% correction at +13% eye opening; 1.0 reaches 66% at +14%). It needs a `label` above it, the live value in `stat` type to its right so the number is exact, and both end labels in `caption` (`0` = "qovoq saqlanadi", `1` = "kuchli tuzatish") so the trade-off reads without opening a tooltip.

Track is `surface-400`, `radius-full`, 4px tall; the filled portion from 0 to the thumb is `accent`. Thumb is a 16px `accent` disc (`radius-full`) with a 2px `surface-100` ring so it separates from the fill at any value; keyboard focus adds the `focus-ring` shadow around the thumb, and arrow keys move it in 0.01 steps to match the CLI's own precision (`--lid-open 0..1`). Dragging updates the `stat` value live, at 150ms most between repaints — fast enough to feel connected to the thumb, slow enough not to compete with the frame counters above it.
