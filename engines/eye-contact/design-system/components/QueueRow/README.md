One video in `Navbat`. Filename in `body-strong` (so it survives being scanned in a list of five), a `caption` line under it with the facts a person checks before trusting a batch job — resolution, duration, file size, straight from `ffprobe`: "1920×1080 · 13 min 19 s · 2.4 GB". A StatusBadge sits top-right of the row; a ProgressBar spans the full width underneath, but only while `ishlanmoqda` or `toʻxtatildi` — a `navbatda` or `tayyor` row shows no bar at all, so an empty or full one never has to be read as "doing nothing" vs. "just finished." The row's own remove `icon` button appears on hover, at the far right, vertically centred against the filename, not the bar.

The row's fill never changes with status — always `surface-200` at rest, `surface-300` on hover — the StatusBadge is the only colour cue; this is deliberate (see Colour in the brand book) so five rows in five different states don't turn the queue into a striped status board before anyone reads a single word. `space-3` internal padding, `1px` `border` rule between rows (not around each one), `radius-md` only on the list's own four corners.
