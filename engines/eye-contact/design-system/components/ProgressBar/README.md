A determinate bar (`report.json` always knows `frames_total`; there is no indeterminate state) paired with a `stat`-type line of live figures on the right: frame count, kadr/s, and remaining time — the three numbers the spec's own progress row names (9.1). Track is `surface-400`, `radius-full`; the fill's colour follows the row's StatusBadge exactly, so the two never disagree: `accent` while `ishlanmoqda`, frozen in `muted` the instant a job is `toʻxtatildi` (the fill stops moving but keeps its last width — never resets to zero), `danger` only if the whole file fails outright rather than skipping individual frames.

Width transitions 150–200ms ease-out on update; the numeric line never tweens — each figure snaps to its new value the moment `report.json` reports it, because these are measured counts, not an animation settling into place. 6px tall bar, `space-2` gap to the stat line, both sit inside a QueueRow's own padding rather than adding their own.
